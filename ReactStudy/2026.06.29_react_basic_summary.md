# 📝 React 기초 개념 정리: 역할 분담과 구조분해 할당

강사님이 강조하신 핵심 원리들을 직관적으로 이해할 수 있도록 정리한 문서입니다.

---

## 1. ⏱️ 초시계의 역할 분담 (화면은 누가 그릴까?)

> **질문:** 화면 그리는 게 `root2Element` 이고, 화면 그리는 게 `setInterval` 코드인겨?
> **답변:** 반은 맞고 반은 틀립니다! 각 코드의 정확한 역할은 아래와 같이 나뉩니다.

### 🏗️ 역할 분담 요약

* **`root2Element` (도화지가 놓일 자리)**
  * HTML에 있는 `<div id="root2"></div>`를 자바스크립트로 가져온 것입니다. 
  * 직접 그리는 기능은 없고, **"여기에 React 그림을 그릴 것이다"**라고 위치를 지정해 주는 '바탕' 역할을 합니다.
* **`root2` (그림을 그리는 화가)**
  * `ReactDOM.createRoot(root2Element)` 코드를 통해 탄생한 **실제 화가(객체)**입니다.
  * 이 화가에게 `.render(그림)`을 명령해야 비로소 화면에 결과물이 그려집니다. **실질적으로 화면을 그리는 주체는 이 녀석입니다.**
* **`setInterval` (1초마다 깨우는 알람)**
  * 얘는 스스로 화면을 그리는 능력이 없습니다.
  * 대신, **"1초마다 새로운 시간 그림을 만들어서, 화가(`root2`)에게 다시 그리라고 명령"**하는 반복 실행기 역할을 합니다.

### 🔄 1초마다 일어나는 일의 흐름
1. **`setInterval` (알람):** "1초 지났다! 얼른 일해라!"
2. **코드 내부:** 현재 시간을 확인해서 새로운 React 엘리먼트(`container`)를 만듦.
3. **`root2.render(container)` (화가):** 명령을 받고 지정된 도화지(`root2Element`)에 새 그림을 덮어씌워서 그 화면을 갱신함.

## 2. 📦 React, ReactDOM을 꺼내는 코드의 비밀

```javascript
const { React, ReactDOM } = window;
```

> **질문:** 이 코드를 반드시 알아야 한대. 이게 도대체 뭔데?
> **답변:** 브라우저 환경이라는 거대한 창고에서 **"내가 쓸 리액트 도구 상자만 쏙 뽑아서 쓰겠다"**고 선언하는 **구조분해 할당(Destructuring)** 문법입니다.

### 🔍 비유로 이해하기
HTML에 CDN(스크립트 주소)을 넣으면, 브라우저의 전역 공간인 `window`라는 거대한 창고에 `React`와 `ReactDOM`이라는 거대한 도구 상자가 자동으로 입고됩니다.

* **`React` 상자:** 화면의 부품(Element)을 **만드는** 도구 세트 (`createElement` 등)
* **`ReactDOM` 상자:** 만든 부품을 브라우저에 **그리는** 도구 세트 (`createRoot` 등)

### 🧐 왜 굳이 이 코드를 써서 꺼내야 할까?
이 코드를 쓰지 않으면, 매번 리액트 명령어를 쓸 때마다 창고 주소(`window.`)를 앞에 붙여야 해서 코드가 엄청 길어지고 지저분해집니다.

* **꺼내지 않았을 때 (불편함):**
  ```javascript
  window.React.createElement(...);
  window.ReactDOM.createRoot(...);
  ```
* **구조분해 할당으로 쏙 꺼내두었을 때 (편안):**
  ```javascript
  React.createElement(...);
  ReactDOM.createRoot(...);
  ```

### 💡 강사님이 "반드시 알아야 한다"고 강조한 진짜 이유
요즘 현업(현대 리액트)에서는 이 방식을 쓰지 않고 `import React from 'react';`라는 빌드 시스템 문법을 사용합니다. 

그럼에도 이 레거시 문법을 먼저 배우는 이유는, 나중에 최신 문법을 배울 때 **"아, 최신 `import` 문법도 결국 옛날에 `window` 창고에서 구조분해 할당으로 꺼내 쓰던 원리랑 똑같은 거구나!"** 하고 리액트가 구동되는 **근본적인 데이터 흐름과 원리**를 깨닫게 하기 위함입니다.
