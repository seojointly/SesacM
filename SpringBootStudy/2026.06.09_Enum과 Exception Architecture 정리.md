## 1. enum(Enumeration)의 정의와 특징

### ① enum이란 무엇인가?
* **정의**: 서로 연관된 고정된 상수(변하지 않는 값)들의 집합을 뜻하는 문법입니다.

## 2. 예외 처리 아키텍처: enum vs class의 역할 분담

예외 처리 구조를 설계할 때 `enum`과 `class`는 각각 **규격서(데이터)**와 **캐리어(기능)**의 역할로 완벽히 분할되어 협력합니다.

| 구성 요소 | 비유 | 주요 역할 |
| :--- | :--- | :--- |
| **`enum` (예외 코드)** | **에러 메뉴판 / 규격서** | 시스템 전반에서 발생할 수 있는 에러의 종류, HTTP 상태 코드, 클라이언트용 에러 메시지를 **중앙 집중식으로 정의하고 관리**합니다. |
| **`class` (Custom Exception)** | **에러 배달원 / 캐리어** | 프로그램 런타임 중 에러가 터졌을 때, `enum` 데이터를 품고 **실제로 `throw`되어 외부로 전달되는 기능적 주체**입니다. |

### 💡 왜 분리해서 사용할까?
자바를 포함한 대부분의 언어에서 에러를 던질(`throw`) 때는 반드시 `Throwable`이나 `Exception`을 상속받은 **클래스 객체**여야 합니다. `enum`은 규격일 뿐 스스로 던져질 수 없기 때문에, `Exception` 클래스가 이 `enum`을 담아서 움직이는 역할을 해주는 것입니다.

    }

    }
}
