## 1. 이터러블(Iterable)이란?
**이터러블(Iterable)**은 직역하면 **'반복 가능한'**이라는 뜻입니다. 프로그래밍에서는 **`for`문을 돌려서 내부의 요소들을 하나씩 꺼내 쓸 수 있는 객체(데이터 구조)**를 말합니다.

* **대표적인 이터러블 종류:** 배열(Array), 문자열(String), Map, Set 등
* **특징:** 데이터들이 순서대로 나열되어 있으며, 컴퓨터가 "다음 데이터 가져와!"라고 요청할 수 있는 구조를 가지고 있습니다.

---

## 2. 포이치(forEach)가 뭐임?

**포이치(forEach)**는 JavaScript, Java, C# 등 여러 프로그래밍 언어에서 제공하는 **배열(Array) 전용 반복문 메소드(함수)**입니다.

일반 `for`문처럼 인덱스(`i`)를 만들고 숫자를 키워가며 수동으로 꺼내는 것이 아니라, **"배열 안의 아이템들을 처음부터 끝까지 자동으로 하나씩 꺼내서 이 코드를 실행해 줘!"**라고 컴퓨터에게 시키는 편리한 기능입니다.

### 💻 JavaScript 기준으로 비교하기

만약 `['🍎', '🍌', '🥝']` 배열의 요소를 모두 출력하고 싶다면 어떻게 다를까요?

#### [방식 1] 일반 `for`문 (수동 방식)
```javascript
let fruits = ['🍎', '🍌', '🥝'];

for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]); // 수동으로 인덱스 i를 사용해 접근
}
[방식 2] forEach 메소드 (자동 방식)
JavaScript
let fruits = ['🍎', '🍌', '🥝'];

// 배열아, 너가 가진 요소를 하나씩 꺼내서 바로 출력해줘!
fruits.forEach(function(fruit) {
    console.log(fruit); 
});
장점: i 변수를 만들 필요도 없고, 배열의 길이를 잴 필요도 없어서 코드가 훨씬 직관적이고 깔끔해집니다.

① 문자열(String)은 원래 for문이 돌아갑니다
문자열도 내부적으로 글자들이 순서대로 나열된 이터러블(Iterable)이기 때문에, 굳이 변환하지 않아도 일반 for문이나 for...of문으로 글자를 하나씩 꺼낼 수 있습니다.

JavaScript
for (let char of "hello") {
    console.log(char); // 'h', 'e', 'l', 'l', 'o' 순서대로 출력 가능!
}
② 하지만 문자열에 forEach를 바로 쓰면 에러가 납니다
forEach는 오직 배열(Array)의 전용 무기입니다. 문자열에 그냥 사용하면 컴퓨터가 이해하지 못합니다.

JavaScript
let str = "hello";
str.forEach(char => console.log(char)); // ❌ 에러 발생 (TypeError)
③ 결론: "문자열을 '배열'로 바꿔서 포이치를 돌린다"가 맞습니다!
질문하신 프로세스는 문자열(String)을 글자 단위로 쪼개서 배열(Array)로 만든 다음, forEach를 사용하는 과정을 의미하신 것입니다.

JavaScript
let str = "hello";

// 1. split("")을 사용해 문자열을 배열로 쪼갭니다.
// 결과: ['h', 'e', 'l', 'l', 'o']
let arr = str.split(""); 

// 2. 이제 배열이 되었으므로 전용 무기인 forEach를 사용할 수 있습니다!
arr.forEach(char => {
    console.log(char);
});

forEach: 배열 전용 자동 반복문. 인덱스 없이 깔끔하게 순회할 때 사용.

문자열과 포이치: 문자열에 forEach를 쓰려면, 먼저 문자열을 배열로 변환(split)한 뒤에 사용해야 한다!
