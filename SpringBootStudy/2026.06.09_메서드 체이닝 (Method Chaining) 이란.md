# 🔗 메서드 체이닝 (Method Chaining) 이란?

**메서드 체이닝(Method Chaining)**은 메서드들을 사슬(Chain)처럼 줄줄이 연결해서 호출하는 프로그래밍 패턴입니다. 
하나의 실행문 안에서 점(`.`)을 찍고 여러 메서드를 연속해서 호출하는 기술을 말합니다.

---

## 1. 코드로 보는 직관적인 차이

"문자열을 대문자로 바꾸고, 공백을 제거한 뒤, 특정 글자를 변경"하는 작업을 기준으로 비교해 보겠습니다.

### ① 일반적인 방식 (메서드 체이닝 미사용)
매 단계마다 변수를 새로 만들거나 덮어써야 해서 코드가 길어지고 복잡해집니다.

```java
String str = "  hello world  ";

String upperStr = str.toUpperCase();          // 1. 대문자로 변경
String trimmedStr = upperStr.trim();          // 2. 공백 제거
String result = trimmedStr.replace(" ", "_"); // 3. 공백을 언더바로 변경
② 메서드 체이닝 방식
이전 메서드의 결과물에 곧바로 점(.)을 찍어 다음 작업을 이어 나갑니다. 코드가 훨씬 직관적입니다.

Java
String result = "  hello world  "
                .toUpperCase()      // 1. "  HELLO WORLD  " 반환
                .trim()             // 2. "HELLO WORLD" 반환
                .replace(" ", "_"); // 3. "HELLO_WORLD" 반환
2. 메서드 체이닝의 핵심 원리
"어떻게 점(.)을 계속 찍을 수 있는가?"에 대한 답은 간단합니다.

"메서드가 작업을 마친 뒤, 자기 자신(this) 또는 가공된 객체 자체를 다시 반환(return)"하기 때문입니다.

💡 자바 코드로 보는 원리 예시
Java
public class Person {
    private String name;
    private int age;

    // 객체 자신(this)을 반환하는 메서드
    public Person setName(String name) {
        this.name = name;
        return this; // 🌟 핵심: 나 자신(Person 객체)을 그대로 돌려줌!
    }

    // 객체 자신(this)을 반환하는 메서드
    public Person setAge(int age) {
        this.age = age;
        return this; // 🌟 핵심: 나 자신(Person 객체)을 그대로 돌려줌!
    }
}
이 클래스를 사용할 때 아래와 같이 체이닝이 가능해집니다.

Java
Person person = new Person();

// setName()이 실행된 자리에 다시 person 객체가 남기 때문에 곧바로 .setAge() 호출 가능
person.setName("홍길동").setAge(20); 
3. Spring Framework 코드와의 연결
스프링 예외 처리(GlobalExceptionHandler) 등에서 자주 쓰는 아래 코드도 정확히 이 원리로 작동합니다.

Java
return ResponseEntity.status(HttpStatus.BAD_REQUEST).body(errorResponse);
ResponseEntity.status(HttpStatus.BAD_REQUEST)를 호출하면, 내부적으로 HTTP 상태 코드가 담긴 빌더(Builder) 객체가 반환됩니다.

반환된 빌더 객체에 곧바로 점(.)을 찍고 .body(errorResponse)를 호출하여 최종 응답 객체를 완성합니다.

🎯 메서드 체이닝을 쓰는 이유
가독성 향상: 불필요한 중간 변수 선언이 사라지고, 코드가 위에서 아래로 물 흐르듯 읽힙니다.

유지보수 편의성: 중간에 추가하고 싶은 설정이나 작업이 있다면 줄만 하나 더 끼워 넣으면 되므로 유연하게 대처할 수 있습니다.
